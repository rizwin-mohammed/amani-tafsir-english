# Source of the Arabic Quran text

`quran-uthmani.json` holds the Uthmani Quran text (6,236 verses) from the npm package
[quran-json 3.1.2](https://www.npmjs.com/package/quran-json), which takes it from
[The Noble Qur'an Encyclopedia](https://quranenc.com/en/home).

The Arabic of every verse on the site is taken from this file at build time. It is never
typed by hand or read from page images, so the Quran text itself cannot be mistyped.
