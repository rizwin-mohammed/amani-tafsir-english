# Amani Tafsir in English

An English translation of *Vishuddha Quran Vivaranam*, the Malayalam translation and commentary of the Holy Quran by Muhammad Amani Moulavi.

The website is built from this repository. A surah appears on the site only after it has been translated, checked and approved.

## Where things are

| Folder | What it holds |
| --- | --- |
| `content/en/` | The English translation, one folder per surah (for example `001-al-fatihah`) |
| `content/glossary.md` | Fixed English renderings of key terms, used in every surah |
| `data/quran-uthmani.json` | The verified Arabic Quran text (see `data/SOURCE.md`) |
| `scripts/` | The tools that check the text and build the website |
| `site/assets/` | The website's design and reader features (bookmarks, notes, search) |
